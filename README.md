# 설대영어 단어퀴즈 GitHub 배포본 v8 — 통합 채점엔진 4.0

최종 갱신: 2026-09-03

이번 버전의 핵심은 개별 단어 예외추가가 아니라 모든 앱의 실제 채점 경로를
`SEOLDAE_GRADE_V40` 하나로 통일한 것입니다.

## 채점 원칙
- `[ ]`는 정답 문자열의 일부가 아니라 대체 가능한 의미로 자동 확장
  - 해외에[로] → 해외에 / 해외로
  - 외국에[으로] → 외국에 / 외국으로
  - 감명[감동]을 받은 → 감명을 받은 / 감동을 받은
  - 소비[소모]하다 → 소비하다 / 소모하다
  - 가정[추정]하다 → 가정하다 / 추정하다
- 띄어쓰기와 일반적인 조사 차이는 의미를 바꾸지 않는 범위에서 무시
  - 감명을 받은 ↔ 감명받은
- 명백한 한국어 유의어는 의미군으로 폭넓게 인정
- 철자오타를 글자 유사도로 억지 정답 처리하는 fuzzy matching은 사용하지 않음
- 품사가 명백히 다른 경우 `품사가 다릅니다` 판정 가능
- 대명사는 격을 구분해 엄격 채점
- 한글→영어는 표제어가 기본이며, 확실한 영어 동의어군만 인정

## 대표 회귀 테스트
- overseas / 해외로 → 정답
- overseas / 외국으로 → 정답
- impressed / 감명받은 → 정답
- impressed / 감동받은 → 정답
- consume / 소비하다 → 정답
- consume / 소모하다 → 정답
- assume / 추정하다 → 정답
- assume / 추측하다 → 정답
- benefit / 이득 → 정답
- benefit / 애득 → 오답
- tolerant / 허용하다 → 품사 불일치(형용사 뜻 요구 시)
