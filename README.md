# 설대영어 단어퀴즈 GitHub 배포본 v3

최종 갱신: 2026-09-02

이 패키지는 기존 학생 링크를 유지하기 위해 기존 영문 폴더명을 그대로 사용합니다.
각 폴더의 index.html만 현재 최종본으로 교체합니다.

## 포함 폴더
- 1hour-elementary : 원아워 초등
- alist-advanced : A-List 초등고난도
- alist-basic : A-List 초등기본
- alist-essential : A-List 초등필수
- hackers-middle : 해커스 중학필수
- junior-voca-advanced : 주니어보카 실력
- junior-voca-basic : 주니어보카 기본
- voca-highschool-basic : 능률 VOCA 고교기본
- wordmaster-highschool-basic : 워드마스터 고등베이직

## 현재 최종 발음 규칙
- 영어→한글: 문제 표시 즉시 자동 발음 + 다시 듣기
- 한글→영어: 문제 전 무음, 답 제출 후 자동 발음
- 오답: 정답 영어 자동 발음
- 결과 화면: 오답 단어 다시 듣기
- DAY 이동/화면 복귀 시 TTS 재활성화 및 첫 발화 누락 재시도
