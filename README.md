# 설대영어 단어퀴즈

**현재 활성 데이터-코어 채점본: v20.0**

이번 버전은 유사어 wrapper에만 의존하지 않습니다.
각 단어의 실제 `kor_full` 채점 데이터 자체에 승인 의미를 직접 병합했습니다.
따라서 구형 채점함수/신형 채점함수 어느 경로가 호출되어도 같은 승인 의미를 읽습니다.

핵심 회귀:
- constant → 끊임없는
- trail → 흔적
- consume → 소비하다
- assume → 가정하다 / 추정하다 / 추측하다
- distress → 번민
- instance → 예
- establishment → 설립
- intensely → 강렬하게
- strictly → 엄격하게
