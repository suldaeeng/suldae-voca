## v4 발음 수정
- 영어→한글: 문제 표시 시 자동 발음 + 학생이 한글 뜻을 제출한 뒤 영어 단어를 다시 자동 발음
- 한글→영어: 문제 전에는 무음, 답 제출 후 영어 정답 자동 발음
- 정답/오답 모두 제출 직후 목표 영어 단어를 1회 발음
- 오답 결과 화면: 각 단어의 다시 듣기 버튼 유지
- DAY 이동/화면 복귀: TTS 재활성화 및 첫 발화 누락 재시도 유지
- 소리 확인: 브라우저가 허용하는 최대 음량(volume=1.0) 사용, 짧은 Hello 한 번 대신
  'Hello! Hello! Sound check.'로 더 분명하게 확인하도록 변경
- 소리가 작을 경우 기기의 '미디어 음량'을 올리도록 화면 안내 추가
