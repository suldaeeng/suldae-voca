# 설대영어 단어퀴즈 GitHub 배포본 v8 — 통합 채점엔진 4.0

최종 갱신: 2026-09-03

이번 버전의 핵심은 개별 단어 예외추가가 아니라 모든 앱의 실제 채점 경로를
`SEOLDAE_GRADE_V40` 하나로 통일한 것입니다.

## 채점 원칙
- `[ ]`는 정답 문자열의 일부가 아니라 대체 가능한 의미로 자동 확장
  - 해외에[로] → 해외에 / 해외로
  - 외국에[으로] → 외국에 / 외국으로
  - 감명[감동]을 받은 → 감명을 받은 / 감동을 받은
  - 소비[소모]하다 → 소비하다 / 소모하다
  - 가정[추정]하다 → 가정하다 / 추정하다
- 띄어쓰기와 일반적인 조사 차이는 의미를 바꾸지 않는 범위에서 무시
  - 감명을 받은 ↔ 감명받은
- 명백한 한국어 유의어는 의미군으로 폭넓게 인정
- 철자오타를 글자 유사도로 억지 정답 처리하는 fuzzy matching은 사용하지 않음
- 품사가 명백히 다른 경우 `품사가 다릅니다` 판정 가능
- 대명사는 격을 구분해 엄격 채점
- 한글→영어는 표제어가 기본이며, 확실한 영어 동의어군만 인정

## 대표 회귀 테스트
- overseas / 해외로 → 정답
- overseas / 외국으로 → 정답
- impressed / 감명받은 → 정답
- impressed / 감동받은 → 정답
- consume / 소비하다 → 정답
- consume / 소모하다 → 정답
- assume / 추정하다 → 정답
- assume / 추측하다 → 정답
- benefit / 이득 → 정답
- benefit / 애득 → 오답
- tolerant / 허용하다 → 품사 불일치(형용사 뜻 요구 시)

## v10 조사·활용형 의미어근 수정
- 원뜻과 학생답의 마지막 조사가 달라도 핵심 장소 의미가 같으면 비교 가능
  - 근처의 / 근처에 / 근처에서 → 핵심 의미 `근처`
  - 해외의 / 해외에 / 해외로 → 핵심 의미 `해외`
- 장소 의미군: 근처 / 인근 / 가까운 곳 / 가까이 / 주변
- 특정 `nearby` 한 단어 예외가 아니라 전체 단어장 공통 규칙
- 품사 안전장치는 유지


## v11 수정
### B as well as A
- 잘못된 실력편 표시: `뿐만 아니라 B도=not only A but also B`
- 수정 표시: `A뿐만 아니라 B도`
- 인정 답:
  - A뿐만 아니라 B도
  - A뿐 아니라 B도
  - A뿐만 아니라 B 역시
- 표제어 끝의 불필요한 `:`도 삭제

### 주니어보카 실력편 오답 다시 듣기
- 결과화면의 각 오답 행을 만들 때 `🔊 다시 듣기` 버튼을 직접 생성
- MutationObserver에 의존하지 않음
- 버튼에 실제 영어단어를 `data-eng`로 직접 저장
- pointerdown에서 음성 세션 활성화
- click에서 해당 영어단어 직접 재생
- 버튼이 CSS로 숨겨지지 않도록 결과화면 스타일도 보강

## v13 TTS 빠른 시작 / 지연 복구
- `therapist`처럼 표기가 정상인데도 발음이 늦게 시작되는 문제를 단어 예외가 아니라 TTS queue 문제로 수정
- 기기 내장(localService) 영어 음성을 우선 선택
- 새 단어 발음 전에 오래 남은 pending queue를 제거
- 발음이 420ms 안에 실제 시작되지 않으면 stale queue 자동 복구 후 재시도
- 두 번째 재시도는 특정 음성 지정 없이 브라우저 기본 영어 TTS로 fallback
- v7 + v12 겹침 구조를 제거하고 v13 하나의 발음 코어로 통합
- 괄호/대괄호 표제어 정리 기능도 v13 코어 내부로 통합

## v14 고교기본 DAY 5 원자료 병합오류 복원
- `achievement`: 성취, 업적
- `critical`: 비판적인; 중요한[중대한], 결정적인
- 누락되어 있던 `eventually`: 결국, 마침내 복원
- DAY5에서 다른 단어 뜻이 뒤에 붙어 있던 항목도 함께 분리
  - accomplish
  - intelligent
  - widespread
  - priority
- `critical`은 DAY5에 정확히 1회만 존재하도록 검증
- `criticize`가 아니라 `critical`이 맞음. `비판적인`은 형용사 `critical`의 뜻임.
