설대영어 단어퀴즈 단일 활성 채점엔진 v12.0

핵심 수정
- 기존 v8/v9/v11을 채점 경로에서 사용하지 않고 v12 grade로 직접 교체
- (), [], 쉼표, 세미콜론, 콜론, 슬래시, 물결표 등 표기기호를 정답 제한 요소로 사용하지 않음
- 괄호/대괄호 대체어 전개: 제한[한정]하는 -> 제한하는 / 한정하는
- 조사/띄어쓰기/자연스러운 어미·접사 변형을 폭넓게 정규화
- 승인된 교차 단어장 한국어 뜻을 후보에 포함
- 광범위 부분 의미 및 의미뿌리 유사어 인정
- borrow/lend, rise/raise, 대명사 등 STRICT 항목은 의미 방향을 유지
- 학생 화면의 개발용 엔진 버전 문구 제거

회귀검사 필수 사례
strictly -> 엄격하게 / 철저하게
restrictive(제한[한정]하는) -> 제한하는 / 한정하는 / 제한하는 이
